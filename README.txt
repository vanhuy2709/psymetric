Deploy (Netlify example)
1. Sign in at app.netlify.com, choose Add new site > Deploy manually, drag this folder in
2. Domain management > Add domain > psymetric.info (and www)
3. At the domain registrar, add the DNS records Netlify shows
4. Wait for DNS, then turn on HTTPS
